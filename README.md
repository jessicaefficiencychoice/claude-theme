# Efficiency Choice theme for Claude

A theme for the Claude desktop and mobile apps in navy, cream and rose.

- **Light mode:** cream background, navy text and navy buttons.
- **Dark mode:** deep navy background, cream text and rose buttons.
- A soft wash of color fades in at the top of the conversation.

The terminal doesn't draw themes. In the desktop app, the theme shows in sessions that run on your own computer (local sessions).

## Install

In the Claude desktop app: click **+** next to the prompt box, then **Plugins**. Choose **Add marketplace** and enter `jessicaefficiencychoice/claude-theme`, then **Add plugin** and pick **efficiency-choice-theme**.

At the prompt of a terminal session:

```
/plugin install efficiency-choice-theme --marketplace jessicaefficiencychoice/claude-theme
```

Answer `y` to add the marketplace, then press Enter to install it for your user.

From a shell:

```
claude plugin install efficiency-choice-theme --marketplace jessicaefficiencychoice/claude-theme
```
